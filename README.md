# HOODBTC Shop

DePIN hardware storefront — devices that power decentralized networks:
vehicle data devices, hotspots, mapping cameras, weather stations,
precision positioning, and hardware wallets.

Part of the HOODBTC ecosystem. Build. Trade. Own.

## Preview locally

```bash
python3 -m http.server 8811
# open http://127.0.0.1:8811/
```

## Status

Checkout opens at launch. Product data and prices live in `products.js`;
the cart is client-side (localStorage). No accounts, no tracking.
